# Decentralized Hub

A decentralized application platform built on Stacks blockchain.

## Features

- 🔒 Secure wallet integration
- 🌐 Decentralized storage
- ⛓️ Smart contract interactions
- 📱 Responsive design

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- Stacks CLI
- A Stacks wallet

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/decentralized-hub.git
```

2. Install dependencies:
```bash
cd decentralized-hub
npm install
```

3. Configure environment:
   - Copy `settings/Mainnet.example.toml` to Mainnet.toml
   - Copy `settings/Testnet.example.toml` to Testnet.toml
   - Update configuration values as needed

4. Start development server:
```bash
npm run dev
```

## Configuration

The application supports both Mainnet and Testnet environments. Configuration files are stored in the settings directory.

## Testing

Run the test suite:
```bash
npm test
```
